О проекте

Автоматизация расчёта чистой прибыли и оптимизация подбора исполнителей для клининговой компании

Проблема

  • Непрозрачная прибыль по заказам
  • Неоптимальное назначение клинеров
  • Ошибки в расчёте материалов
  • Долгое оформление заказов (15-20 мин)
  • Отсутствие аналитики

Решение

  • Автоматический расчёт за 2 секунды
  • Алгоритм подбора по максимальной прибыли
  • Точность расчёта материалов >99%
  • Мобильное приложение для операторов
  • Дашборд аналитики для руководства

Математическая модель

Ядро системы — алгоритм расчёта чистой прибыли и подбора оптимального исполнителя

Расчёт себестоимости

C = C_mat + C_labor +
    C_logistics + C_overhead

где:
• C_mat = Σ(S × N_i × K × P_i)
• C_labor = (T_base / V_j) × R_j
• C_logistics — API карт
• C_overhead — 15% от выручки

Критерий оптимальности

P_j = R - C_j

j_opt = argmax(P_j)

Система ранжирует всех
доступных клинеров по
убыванию чистой прибыли
